ПРОЕКТ
Название: LAST SHIFT

Жанр:
Минималистичная 3D warehouse game с лёгкими элементами хоррора.

Концепция:
Игрок работает один на ночной смене небольшого склада.

Игровой процесс максимально простой:

1. Игрок получает заказ на терминале.
2. Заказ содержит несколько типов коробок и их количество.
3. Игрок перемещается по складу.
4. Подходит к нужной коробке.
5. Нажимает кнопку X, чтобы подобрать коробку.
6. Собирает весь заказ.
7. Относит коробки в зону погрузки.
8. Получает деньги/очки.
9. Появляется следующий заказ.
10. Всего 5 заказов.
11. После выполнения пятого заказа показывается экран окончания смены.

Пример заказа:

ORDER #01

BOX A x2
BOX B x1
BOX C x3

DELIVERY: LOADING BAY

TIME: 03:00


ГРАФИКА

Нужна минималистичная low-poly 3D графика, напоминающая ранние 3D игры для PSP/PS2/PS1.

Не нужно стремиться к реалистичной графике.

Сцена должна состоять из простых геометрических объектов:

- пол;
- стены;
- стеллажи;
- коробки;
- паллеты;
- терминал;
- погрузочная зона;
- дверь;
- несколько ламп.

Большинство объектов можно создавать из кубов.

Не нужны сложные модели.

Не нужны сложные текстуры.

Предпочтение:
vertex colors + простые текстуры + простое освещение.

Цель — высокая производительность и минимальный объём кода.


КАМЕРА

Вид от третьего лица.

Камера находится немного выше и позади персонажа.

У PSP только один аналоговый стик, поэтому НЕ использовать управление отдельной камерой.

Камера должна автоматически следовать за игроком.

Допускается фиксированный угол камеры или очень простое автоматическое следование.

Не использовать dual-stick control.


УПРАВЛЕНИЕ

Analog stick:
движение персонажа.

X:
подобрать / положить коробку / взаимодействовать.

Triangle:
открыть текущий заказ.

START:
pause.

SELECT:
не требуется.

L/R:
не требуется.

Управление должно быть простым и отзывчивым.


ИГРОК

Простой low-poly персонаж.

Не нужна сложная скелетная анимация.

Если полноценная модель персонажа усложняет проект, сначала использовать простой low-poly placeholder.

Нужны:

- idle;
- walk.

Если idle/walk animation слишком сложна для первого MVP, допустимо временно использовать статичную модель.


КОРOБКИ

Есть три типа:

BOX A
BOX B
BOX C

Они должны визуально различаться.

Можно использовать разные размеры или простые цвета/текстуры.

Коробку можно подобрать только если игрок находится достаточно близко.

При подборе:

- коробка исчезает из мира;
- увеличивается соответствующий счётчик;
- над игроком или в UI показывается, что коробка взята.

Игрок может переносить только одну коробку одновременно.

Например:

CARRYING:
BOX A


СКЛАД

Создай одну небольшую фиксированную карту.

Не нужен open world.

Не нужна процедурная генерация.

Не нужен физический симулятор.

Стеллажи являются статическими препятствиями.

Коробки также можно считать статическими объектами до момента подбора.

Нужны простые collision checks.

Не использовать сложную physics engine.
